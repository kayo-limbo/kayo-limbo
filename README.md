## Featured Project

### [Personal Knowledge Agent](https://github.com/kayo-limbo/personal-knowledge-agent)

A production-oriented AI knowledge workspace with hybrid retrieval, tool calling,
streaming responses, verifiable citations, and role-based access control.

`Next.js` · `TypeScript` · `React` · `PostgreSQL` · `pgvector` · `Prisma` · `Docker`

- Agent loop with controlled multi-step tool execution
- Hybrid knowledge retrieval with embeddings and PostgreSQL full-text search
- Streaming chat with source citations and conversation persistence
- Authentication, RBAC, knowledge management, prompts, and usage limits
- Docker deployment, database migrations, automated testing, and CI
